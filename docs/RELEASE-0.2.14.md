# Arcade Library Manager 0.2.14

Library now has a Genre button and genre column. Choose Racing, then Select missing shown and Plan selected games to review only missing racing games. Categories come from TeknoParrot metadata; Racer and Driving map to Racing, while games without genre metadata appear under Unspecified. Search, genre and installation-status filters work together.

Install and maintenance review inputs exclude checked games hidden by the current filters. Select missing shown and Select all shown replace the selection; Clear selection clears every checkmark. Maintenance's explicit Use all candidate profiles clears filters before selecting the whole catalog. Existing regional/version selection rules still apply.

Validation covers genre aliases, multiple genres, unknown metadata, exact category matching, hidden-selection exclusion, bulk selection, combined filters and normal/minimum-window desktop layouts. No live game installation is started by this update.
