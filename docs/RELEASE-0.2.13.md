# Arcade Library Manager 0.2.13

The top toolbar now has a solid black background with the existing neon divider and buttons. The native Windows title bar is also black with white caption text on Windows 11; standard dragging and minimize/maximize/close controls are retained. High-contrast mode and older Windows versions retain their system title bar.

This release changes appearance only. Validation uses the published startup/settings check, desktop smoke checks and visual review; the core integration results from 0.2.12 remain applicable.
