# Arcade Library Manager 0.2.11

Fixes dark-theme readability in Emumovies snap scrapper while a preview or video job is running. Labels, descriptions, fallback options and selected catalog values retain readable contrast. Input choices stay locked to the active request, and progress, cancellation and reports remain available.

Includes the video-only scraper introduced in 0.2.10, with the same preserved settings and download caches. No media is downloaded automatically at startup.
