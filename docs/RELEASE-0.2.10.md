# Arcade Library Manager 0.2.10

Adds **Emumovies snap scrapper** immediately above Make themes. The page connects official EmuMovies Sync 2.71 to LaunchBox video folders, with separate platform/catalog choices, preview, download/import, staged-video import, reports, and cancellation.

TeknoParrot PC arcade and classic hardware profiles use their matching catalogs. Other platforms can select a catalog explicitly. Only gameplay videos are downloaded/imported; existing videos, artwork, game XML, and theme videos are preserved. Settings and reports use the existing app data directory. Sign in through official Sync; this app stores no EmuMovies credentials.

Keep Sync open during a run. Missing catalog matches remain in reports. LaunchBox can remain open while videos are copied. This feature does not repair LaunchBox's built-in EmuMovies search.
