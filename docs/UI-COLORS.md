# Interface colors

Version 0.2.1 uses the palette from the user-supplied `FFB-Blaster-MASTER-0.2.0-beta.16-portable.zip`. Its embedded stylesheet was read without launching the application. The reference executable is not included in this distribution.

| Role | Color |
| --- | --- |
| Background | `#07050D` |
| Cards | `#100A1C` |
| Raised panels/buttons | `#170F28` |
| Field background | `#0B0715` |
| Borders | `#2B1B45` |
| Primary accent | `#FF2D95` |
| Secondary accent | `#16E0FF` |
| Amber | `#FFC247` |
| Text | `#ECE2FF` |
| Muted text/examples | `#9784B8` |

Setup examples are display hints, never saved values. They use the current test paths for the TeknoParrot emulator, ROMs, LaunchBox, theme examples, MAME artwork, download cache, FFmpeg, and 7-Zip. No active bezel import folder was configured, so that field is explicitly labeled as an example. Windows title bars, scrollbars, and native file dialogs retain the system appearance.
