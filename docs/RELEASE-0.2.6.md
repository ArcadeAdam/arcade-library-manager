# Arcade Library Manager 0.2.6

New themes and previews default to 30 seconds, with an adjustable range of 25–33 seconds in Media studio. Reference presets and saved settings outside that range are brought within the same limits. Short gameplay snaps loop to fill the selected length; longer snaps are trimmed at the output duration.

The accepted fanart layout and stronger character bounce are unchanged. Existing theme files are preserved.

Validation covers real 25-, 30-, and 33-second outputs, late frames from looped short clips, reference duration limits and invalid values, and the existing motion, media, and integration checks.
